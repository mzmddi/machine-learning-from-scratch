## Matrix class

In my library, everything is considered a matrix, including vectors. This is made for simpler notation. A vector in this library is simply a 1xN or Nx1 matrix.

## Matrix Operations

### Matrix Addition

Order doesnt matter A + B = B + A

### Matrix Substraction

Order matters for the sign of the result only.

`| A - B | = | B - A |` but `A - B != B - A`

### Matrix scaling

`C = A * b`

`C = b * A` will result in an error

### Matrix Matrix multiplication

`C = A % B `
